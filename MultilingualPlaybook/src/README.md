# Vibhasha - The Multilingual Playbook - Source Code

This directory contains the source code and notebooks that support **Vibhasha - The Multilingual Playbook**.

## Purpose of this Material

The materials in this `src` folder provide a comprehensive toolkit for evaluating the quality of machine translations. This is crucial for anyone working with multilingual Large Language Models (LLMs). The tools here allow for both traditional and cutting-edge evaluation methods.

The primary purposes are:
- To provide implementations of standard machine translation evaluation metrics.
- To offer a modern, LLM-based approach for evaluating translation quality, which can provide more nuanced and human-like assessments.
- To supply tools for comparative analysis of different translation models.
- To enable analysis of tokenization, which is a key factor in multilingual model performance.

This toolkit is intended for researchers, developers, and anyone involved in the development and assessment of multilingual AI systems.

## File Structure

The `src` directory is organized as follows:

- `__init__.py`: Makes the `src` directory a Python package.
- `prompt_bank.py`: Stores the prompt templates used for the LLM-as-judge evaluation method.
- `README.md`: This file.
- `evaluations/`: A sub-package containing various evaluation scripts and notebooks.
    - `__init__.py`: Makes `evaluations` a Python sub-package.
    - `translation_evaluation.py`: The core script containing functions to compute various evaluation metrics:
        - `compute_bleu`: Calculates the BLEU score.
        - `compute_chrf`: Calculates the chrF score.
        - `compute_comet`: Calculates the COMET score.
        - `evaluate_with_llm`: Uses a large language model as a "judge" to evaluate translation quality.
    - `elo/`:
        - `Chatbot_Arena_Elo_Rating_Calculation_(July_17,_2023).ipynb`: A Jupyter notebook for calculating Elo ratings, useful for comparing the performance of different translation models against each other.
    - `tokenizer_fertility/`:
        - `tokenizer_fertility_example.py`: A Python script to demonstrate and calculate "tokenizer fertility," a metric to understand how a tokenizer breaks down text in different languages.
        - `tokenizer_fertility_heatmap.png`: A sample visualization generated by the tokenizer fertility script.


## How to Run

To use the evaluation scripts, follow these steps:

### 1. Prerequisites

Ensure you have Python installed. The scripts rely on several external libraries.

### 2. Installation

Install the necessary Python packages using pip:

```bash
pip install sacrebleu litellm "unbabel-comet>=2.0.0" torch
```

### 3. Environment Variables

To use the `evaluate_with_llm` function, you need to set your `OPENROUTER_API_KEY` as an environment variable. This function uses OpenRouter to access various LLMs for evaluation.

For PowerShell:
```powershell
$env:OPENROUTER_API_KEY="your_api_key_here"
```

For bash/zsh:
```bash
export OPENROUTER_API_KEY="your_api_key_here"
```

### 4. Running the Evaluations

You can import the functions from `translation_evaluation.py` into your own Python scripts to evaluate your translation models.

Here is a simple example of how to use the `compute_bleu` function:

```python
from src.evaluations.translation_evaluation import compute_bleu

# Your translated sentences
hypotheses = ["This is a test."]

# The reference translations
references = [["This is a test."]]

# Calculate the BLEU score
bleu_score = compute_bleu(hypotheses, references)
print(f"BLEU score: {bleu_score}")
```

### 5. Running the Notebooks

The Jupyter notebook in the `src/evaluations/elo/` directory can be run in any standard Jupyter environment (like Jupyter Lab or VS Code's notebook editor) to perform Elo rating calculations.

### 6. Tokenizer Fertility Analysis

The `tokenizer_fertility_example.py` script can be run directly from the command line to see an example of tokenizer fertility analysis:

```bash
python src/evaluations/tokenizer_fertility/tokenizer_fertility_example.py
```
