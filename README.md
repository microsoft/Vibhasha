# Vibhasha

Vibhasha is an open-source multilingual AI playbook and evaluation benchmark
survey. The website combines practical guidance for building multilingual AI
systems with a data-driven dashboard covering benchmark suites, datasets,
languages, language families, scripts, regions, and task categories.

## Explore

- [Vibhasha playbook](https://microsoft.github.io/Vibhasha/)
- [Evals Dashboard](https://microsoft.github.io/Vibhasha/evals)

Contributions that add a multilingual evaluation benchmark or improve existing

General contribution requirements, including the Microsoft Contributor License
