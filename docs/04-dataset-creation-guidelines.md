## Dataset Creation Guidelines

Collecting and curating speech datasets demands a rigorous set of criteria. For low-resource languages, it is essential that curation practices reflect the language’s real-world use cases. This approach enables models to learn from a rich and varied dataset which is crucial in scenarios where data is scarce.

### About
> This section outlines a few best practices for dataset curation, with a focus on genuine real-world language use and the importance of diversity
