## Essential metadata to collect

Speaker demographics such as age, gender, region/origin and languages spoken significantly shape vocabulary, pronunciation, and linguistic variety—including accents and dialect. Various metadata allows capturing accents, regional diversity and demographic influences. The metadata should include at a minimum: `speaker id`

| Metadata Item | Essential | Preferred | Use case |
|--------------|:---------:|:---------:|----------|
| **Identity and Demographics** | | | |
| Speaker id (anonymised) | ✓ |  | Unique speaker number and must be anonymised. |
| Gender | ✓ |  | Ensures balanced representation in dataset splits using an inclusive sampling method. |
| Age group | ✓ |  | Part of general metadata and used for sampling. |
| Education level |  | ✓ | Part of demographic metadata and can influence speech patterns like accents. |
| Occupation |  | ✓ | Part of comprehensive demographic metadata. |
| **Geographical Accent Info** | | | |
| Country | ✓ |  | Useful for regional evaluation and analysis. |
| Accent | ✓ |  | Essential to capture multi-accent variations. |
| Current location |  | ✓ | Provides insight into linguistic and regional diversity. |
| Birthplace |  | ✓ | Provides insight into linguistic and regional diversity—part of speaker background. |
| Duration of current residence |  | ✓ | Provides insight into linguistic and regional diversity—part of speaker background. |
| **Linguistic Profile** | | | |
| How many languages they speak (Multi-lingualism) |  | ✓ | Falls under the category of "multilingualism level" to provide insights into linguistic diversity. |
| Disclosed speech disabilities |  | ✓ | Collected as "disclosed disabilities (speech-related or otherwise)" to gain insight into speech pattern variations. |
